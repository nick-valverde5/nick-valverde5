## Featured Projects
### Healthcare No-Show Analysis

Analyzed 110,000+ real medical appointment records using Python (pandas, matplotlib, seaborn) to identify patterns in patient no-shows and provide actionable recommendations for reducing missed appointments.

**Key Findings:**
- Overall no-show rate: 20.2% — 1 in 5 patients missed their appointment
- Same-day appointments had only 6.6% no-show vs 33.2% for 31–90 day waits
- Young adults (19–35) had the highest no-show rate at 23.8%
- High-risk neighbourhoods: Santos Dumont, Santa Cecília, Santa Clara
